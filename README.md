# Better Offensive Installer

Lightweight Windows installer for Better Offensive.

## Usage
- Download the latest release from the [releases page](https://github.com/NotIlluMinAty/BetterOffensiveInstaller/releases/latest)
- Run the tool
- Select your game's installation directory and click install
- Launch the game from Steam.

## Building
Requirements:
- .NET 8 SDK

`dotnet publish -c Release -r win-x64`
